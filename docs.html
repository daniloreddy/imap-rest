IMAP REST API

API REST per operazioni IMAP/SMTP. Progettata per integrazione con n8n via HTTP Request node.

http://localhost:8000
🔑

Autenticazione

Ogni richiesta (tranne /health) richiede l'header Authorization: Bearer <token>.
Il token deve corrispondere a uno di quelli configurati in API_TOKENS (dashboard o env). Se API_TOKENS è vuoto, gli endpoint restano aperti (solo uso locale/rete fidata).

Account — credenziali server-side

Le credenziali non si passano nella request. Ogni endpoint accetta "account": "<nome>"; il server risolve le variabili d'ambiente corrispondenti.

VariabileDefaultDescrizione
IMAP_<ACCOUNT>_HOSTrichiestoHostname IMAP
IMAP_<ACCOUNT>_PORT993Porta IMAP
IMAP_<ACCOUNT>_USERNAMErichiestoUtente IMAP
IMAP_<ACCOUNT>_PASSWORDrichiestoPassword IMAP
IMAP_<ACCOUNT>_SSLtrueSSL/TLS
SMTP_<ACCOUNT>_HOSTrichiestoHostname SMTP
SMTP_<ACCOUNT>_PORT587Porta SMTP
SMTP_<ACCOUNT>_USERNAMErichiestoUtente SMTP
SMTP_<ACCOUNT>_PASSWORDrichiestoPassword SMTP
SMTP_<ACCOUNT>_STARTTLStrueSTARTTLS
SMTP_<ACCOUNT>_SSLfalseSSL diretto (porta 465)

Il nome account viene convertito in maiuscolo: "danilo" → IMAP_DANILO_HOST. Account non configurato → 400.

Messaggi
POST

/messages/list

Recupera gli header di tutti i messaggi a partire da un UID. Utile per sincronizzazione incrementale: passa since_uid per ottenere solo i messaggi nuovi rispetto all'ultima lettura.

application/json
{
  "account":   "danilo",
  "folder":    "INBOX",
  "since_uid": "1040",
  "limit":     100
}
CampoTipoDefaultDescrizione
folderstring"INBOX"Cartella da listare
since_uidstringnull (tutti)Ritorna solo messaggi con UID > questo valore (esclusivo — passa l'ultimo UID già processato)
limitint100Max messaggi; null/assente = 100, negativo = tutti
200 OK
{
  "folder":    "INBOX",
  "since_uid": "1040",
  "count":     3,
  "messages": [
    {
      "uid":        "1040",
      "message_id": "<abc@mail.com>",
      "from":       "Mittente <m@example.com>",
      "to":         "tuo@email.com",
      "cc":         "",
      "subject":    "Oggetto",
      "date":       "Mon, 1 Jan 2025 10:00:00 +0100",
      "flags":      ["\\Seen"],
      "size":       3210
    }
  ]
}
POST

/messages/get

Recupera il contenuto completo di un singolo messaggio: header, corpo testo/HTML e lista allegati.

application/json
{
  "account": "danilo",
  "folder":  "INBOX",
  "uid":     "1042"
}
CampoTipoDefaultDescrizione
folderstring"INBOX"Cartella contenente il messaggio
uidstringrichiestoUID del messaggio
200 OK
{
  "uid":        "1042",
  "message_id": "<abc123@mail.com>",
  "from":       "Mittente <m@example.com>",
  "to":         "tuo@email.com",
  "cc":         "",
  "subject":    "Fattura marzo",
  "date":       "Mon, 1 Jan 2025 10:00:00 +0100",
  "flags":      ["\\Seen"],
  "body_text":  "Testo in chiaro del messaggio...",
  "body_html":  "<html>...</html>",
  "attachments": [
    {
      "filename":     "fattura.pdf",
      "content_type": "application/pdf",
      "size":         48210
    }
  ]
}

404 se l'UID non esiste nella cartella. body_text e body_html sono null se la parte corrispondente non è presente. Gli allegati non includono il contenuto binario — solo metadati.

POST

/messages/search

Cerca messaggi in una cartella. Restituisce i più recenti fino al limite impostato.

application/json
{
  "account":  "danilo",
  "folder":   "INBOX",
  "limit":    50,
  "criteria": {
    "unseen":  true,
    "from":    "mittente@example.com",
    "subject": "fattura",
    "since":   "01-Jan-2025",
    "before":  "01-Jun-2025"
  }
}
CampoTipoDefaultDescrizione
folderstring"INBOX"Cartella da cercare
limitint50Max messaggi restituiti
criteriaobject{} (ALL)Criteri di ricerca
ChiaveTipoDescrizione
unseenboolSolo messaggi non letti
seenboolSolo messaggi letti
fromstringFiltro mittente
tostringFiltro destinatario
subjectstringFiltro oggetto
sincestringDopo data — formato DD-Mon-YYYY (es. 01-Jan-2025)
beforestringPrima di data — stesso formato
bodystringTesto nel corpo del messaggio
rawstringStringa IMAP grezza (es. "UID 100:200")

Più criteri vengono combinati con AND. Omettere criteria o passare {} restituisce tutti i messaggi (ALL).

200 OK
{
  "folder":   "INBOX",
  "criteria": "UNSEEN FROM \"mittente@example.com\"",
  "count":    2,
  "messages": [
    {
      "uid":        "1042",
      "message_id": "<abc123@mail.com>",
      "from":       "Mittente <mittente@example.com>",
      "to":         "tuo@email.com",
      "cc":         "",
      "subject":    "Fattura marzo",
      "date":       "Mon, 1 Jan 2025 10:00:00 +0100",
      "flags":      [],
      "size":       4821
    }
  ]
}

}

uidsstring[]richiestoLista UID da spostare
destinationstringrichiestoCartella destinazione
200 OK
{
  "moved":       ["1042"],
  "destination": "Archivio"
}

/messages/send

Invia un messaggio via SMTP. Credenziali SMTP separate da quelle IMAP.

application/json
{
  "account":   "danilo",
  "from_addr": "tuo@email.com",
  "to":        ["destinatario@example.com"],
  "cc":        ["copia@example.com"],
  "bcc":       ["nascosto@example.com"],
  "subject":   "Oggetto",
  "body":      "Testo del messaggio",
  "html":      false
}
CampoTipoDefaultDescrizione
from_addrstringrichiestoIndirizzo mittente
tostring[]richiestoDestinatari
ccstring[][]CC
bccstring[][]BCC
subjectstringrichiestoOggetto
bodystringrichiestoCorpo del messaggio
htmlboolfalseCorpo in formato HTML

Le credenziali SMTP (host, porta, username, password, starttls, ssl) vengono risolte da SMTP_<ACCOUNT>_* nel .env.

200 OK
{
  "sent": true,
  "to":   ["destinatario@example.com"],
  "cc":   ["copia@example.com"],
  "bcc":  ["nascosto@example.com"]
}
Errori
401

Token Bearer assente o non valido

Header Authorization: Bearer <token> mancante o diverso da uno dei token configurati in API_TOKENS.

{ "detail": "Invalid or missing API token" }
400

Parametro non valido / account non configurato

Account non presente nel .env, oppure action in /messages/flag diverso da "read"/"unread".

{ "detail": "IMAP account 'xyz' not configured" }
500

Errore IMAP / SMTP

Credenziali errate, server non raggiungibile, cartella inesistente, UID non trovato.

{ "detail": "[AUTHENTICATIONFAILED] Invalid credentials" }
